# Админка (этап 5, основа)

Статус на 2026-11-05: **основа реализована, слита в `main` (PR #5, merge `252196d`) и развёрнута на VPS с ВЫКЛЮЧЕННОЙ админкой** (`/LunexGame/admin/…` → 404 на всех путях; `schemaVersion: 100`, игровой API работает). Включает владелец, см. ниже.
Ветка/PR: `claude/admin-foundation` (слита). Решения этого документа (A1–A10) независимы от нумерации `docs/DECISIONS.md`, чтобы не конфликтовать с параллельной работой над боем; при слиянии их можно перенести туда.

## Что есть
- **Вход владельца** (один пользователь) по паролю. Адрес: `https://tts-ufa.ru/LunexGame/admin/`.
- **Версионированный контент:** черновик → проверка → предпросмотр → ручная публикация → история версий → возврат (всё через веб-интерфейс).
- **Два вида контента для начала:**
  - `energy` — коэффициенты энергии боя (форма из четырёх полей). Предпросмотр **прогоняет демо-бой на настоящем боевом ядре** с черновиком и сравнивает с опубликованными значениями.
  - `heroes` — описания героев (имя, роль, редкость, цвет, базовые характеристики), редактор JSON, проверка по правилам. **Пока не подключено к расчёту боя.**
- **Журнал действий** (вход, неудачный вход, сохранение/сброс черновика, предпросмотр, публикация, возврат) с адресом.
- Адаптивный интерфейс (телефон и ПК), без внешних библиотек.

## Как включить на VPS (делает владелец под root)
Админка **не создаётся**, пока не задан хэш пароля (маршрут остаётся 404). Пароль на сервере не хранится — только хэш argon2id.
1. После деплоя новой версии одной командой получить хэш **и сразу дописать его в файл окружения** (запросы пароля видны на экране, дописывается только итоговая строка):
   ```
   /opt/lunexgame/current/lunexgame hash-password >> /opt/lunexgame/etc/lunexgame.env
   ```
   Команда просит пароль **дважды** (ввод скрыт — символы не отображаются; не короче 12 символов, используйте менеджер паролей).
   **Не копируйте строку с хэшем в `echo "…"`:** в хэше есть символы `$`, в двойных кавычках bash раскроет их и испортит хэш.
2. Проверить и перезапустить службу:
   ```
   tail -c 120 /opt/lunexgame/etc/lunexgame.env     # в конце — строка LUNEXGAME_ADMIN_PASSWORD_HASH='$argon2id$…'
   systemctl restart lunexgame
   journalctl -u lunexgame -n 5 --no-pager          # должна быть строка «админка включена»
   ```
   Если хэш испорчен, служба напишет «ВНИМАНИЕ … админка ВЫКЛЮЧЕНА» и не откроет админку. Повторный запуск шага 1 добавит вторую строку: лишнюю (старую) удалите в `nano /opt/lunexgame/etc/lunexgame.env`.
3. Открыть `https://tts-ufa.ru/LunexGame/admin/` и войти.
Смена пароля: получить новый хэш, заменить строку в `lunexgame.env`, перезапустить службу (все сессии при этом остаются действительными до истечения срока — чтобы сбросить их, выполните `DELETE` из `admin_sessions` или просто подождите 8 часов).

## Безопасность (A1–A6)
- **A1. Закрыто по умолчанию:** нет хэша или он неверного формата → админка не создаётся (404), в журнал пишется причина.
- **A2. Пароль:** argon2id (64 МиБ, t=3, p=2), соль случайная, сравнение за постоянное время; пароль ≥ 12 символов (при создании хэша).
- **A3. Сессия:** 256-битный случайный токен в cookie `HttpOnly; Secure; SameSite=Strict; Path=/LunexGame/admin`; в БД только SHA-256 токена; срок 8 часов, затем вход заново; выход удаляет сессию.
- **A4. CSRF:** все изменяющие запросы требуют заголовок `X-CSRF-Token` (выдаётся при входе) **и** проверку источника (`Origin` и `Sec-Fetch-Site`).
- **A5. Подбор пароля:** не более 5 попыток в минуту с адреса и 20 в минуту всего (защита ресурсов VPS от распределённого подбора); при превышении — 429. Компромисс: массовые попытки могут на время заблокировать и самого владельца — подождите минуту. Адрес берётся из `X-Real-IP`, который выставляет nginx. Неудачные входы пишутся в журнал службы строкой `admin: вход отклонён ip=…` (удобно для будущего правила fail2ban).
- **A6. Страница:** строгая Content-Security-Policy (`default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'; frame-ancestors 'none'`), `X-Frame-Options: DENY`, `nosniff`, `no-referrer`, `Cache-Control: no-store`; весь пользовательский текст вставляется как текст (не как HTML).

## Контент и версии (A7–A10)
- **A7.** Опубликованные версии неизменяемы; версия растёт на единицу. **Возврат = новая версия с копией старых данных**, история сохраняется; прогресс и ресурсы игроков не затрагиваются.
- **A8.** Публикация требует `expectedVersion` (версию, которую владелец видел): если за это время опубликована другая — 409, ничего не теряется молча. Старые данные при возврате должны проходить **текущую** проверку.
- **A9.** Черновик допускает данные с ошибками (можно сохранить недоделанное), но проверка/предпросмотр/публикация их не пропускают. Один черновик на вид контента.
- **A10.** Проверка строгая: неизвестные поля, лишний текст после JSON, выход за границы, неверные роли/редкости/цвета отклоняются с понятными сообщениями.

## Устройство
- `server/internal/admin` — вход, сессии, CSRF, API, встроенный интерфейс (`web/`).
- `server/internal/content` — виды контента и их проверка (`kinds.go`), хранилище версий и журнал (`store.go`).
- Миграция `0100_admin_content.sql` (аддитивная; номер взят с запасом, чтобы не пересекаться с миграциями игровых модулей).
- Единственная точка связи с боем: `server/internal/app/admin_preview.go` (предпросмотр). Остальной код боя админка не трогает.
- Добавить новый вид контента: запись в `content.Kinds` (имя, описание, пример, проверка) + при желании предпросмотр в `admin_preview.go` + при желании форма в `web/app.js` (иначе — редактор JSON).

## Не проверено / ограничения
- **Не включено и не проверено на VPS** (боевой HTTPS, nginx, реальный телефон). Secure-cookie проверена только на `http://127.0.0.1` в Chromium (он допускает её для локального адреса).
- Нет двухфакторной защиты и интерфейса смены пароля.
- Не реализованы (остальной этап 5): редакторы остальных данных (враги, этапы, Башня, экономика, задания, VIP, фракции), загрузка и проверка моделей/анимаций/картинок, оформление экранов (тексты, цвета, размеры), предпросмотр оформления, подключение опубликованного контента к игре.
- Предпросмотр `heroes` пока только сводка состава (не бой).
- Журнал показывает 200 последних записей; фильтров нет.
